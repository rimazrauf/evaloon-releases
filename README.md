# Evaloon Editor releases

Windows installers for Evaloon Editor, an AI video editor for Windows.

## Download

Get the newest installer from the [latest release](https://github.com/rimazrauf/evaloon-releases/releases/latest). Download the `EvaloonEditor-<version>-x64.exe` file and run it.

Requires Windows 10 or 11, 64-bit.

Windows may warn that the installer is from an unknown publisher, because it isn't code-signed yet. Choose "More info", then "Run anyway".
